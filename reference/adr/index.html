Design records

The decisions behind Archi 3.0 are in two architecture decision records (ADRs). They live in the repository, outside this site.

  • ADR 0002: Archi 3.0, automating operations on a solid context layer. What Archi is, the decisions D1 to D13, packs and bundles, the context layer, the operations layer and the setup path. Start here.
  • ADR 0001: Archi v3 program spec. The program the 3.0 release builds on. ADR 0002 amends it.

Other design notes kept in the repository's docs/ folder:

  • OKG alignment page: the OKG surface Archi uses.
  • Upstream asks for the golden path and for the ops runtime: the changes Archi needs from OKG.
  • Cache snapshots: shipping connector caches without CERN access.
  • The long cern-team quickstart, kept as reference.
