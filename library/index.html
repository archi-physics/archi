Bundles and packs in this release

Each page below is generated from the manifest in the repository, so it cannot drift from what ships.

Bundles

Bundle Description
cern-team A generic CERN team knowledge instance - documentation, meetings, wiki, documents, tickets and code.
cluster-manager A cluster manager's knowledge instance - documentation, tickets, operational memory and, optionally, ServiceNow, Slurm, HTCondor, node health and code.
cms-comp-ops A CMS computing operations knowledge instance - sites, storage, datasets and workflows from the CMS catalogs, site status, CMSSW releases, and the operational memory of past incidents.
cms-physics A CMS physics knowledge instance - physics TWiki pages, CDS records, CMSSW releases, analysis notes, and the analysis ids, groups and techniques that link them.

Packs

Pack Kind Description
analysis-notes context CMS analysis notes, read from a local mirror of gitlab.cern.ch/tdr/notes - notes, sections, figures, bibliography and links to TWiki pages.
cds context CERN Document Server records, harvested over the public OAI-PMH endpoint.
cms-analyses context CMS physics group and technique hubs, and rules joining analysis ids across CDS records, TWiki pages and analysis notes (code is not linked).
cms-catalogs context CMS computing catalogs - CRIC, CRIC core, SITECONF, DBS, WMStats, GOCDB and CondDB.
cmssst context CMS Site Support Team site status, from the cache the cmssst downloader writes.
cmssw-releases context The CMSSW release catalog, from the public cms-bot releases.map.
code-symbols context Functions, classes, imports and calls in git-code's repository.
code-text context The text of every text file in git-code's repository (code, Markdown, YAML, scripts, configuration), with Python cut into one chunk per function or class and files holding a literal secret left out.
core-playbooks tool The generic archi playbooks for retrieving, citing and synthesising graph evidence.
docsite context Documentation sites, read from the records cache the static-docs downloader writes.
dqm context CMS DQM data-quality certifications, with the runs and datasets they cover.
git-code context One Git repository's tracked files and history (commits, tags, authors, per-file diffs).
htcondor context An HTCondor pool snapshot (machines, schedds and CPU totals) with live condor_status and condor_q tools.
hypernews context CMS HyperNews forum threads, from a records cache or a live SSO crawl.
indico context Indico events and their talks, read live from the Indico HTTP API.
instance-health automation Watches the instance itself (doctor, source freshness, failed ingests, automation error rates, eval trends) and keeps one issue per problem in the instance repository.
jira context JIRA issues and their participants, read from the cache the JIRA downloader writes.
monit-live context CERN MONIT monitoring snapshots (SAM, HTCondor, Rucio) and the live MONIT query tools.
node-health context Compute-node health from a JSON list of per-node reports that a site's own health exporter writes to node-health/records.json (each report has node, cluster, observed_at and checks, a list of name, status ok or warn or fail, and detail).
ops-record context Operational memory, the incidents, proposals, decisions, actions and outcomes automations record through okg admission (ADR 0002 section 6.2).
servicenow context ServiceNow incidents, requests and knowledge-base articles, read from the records cache the ServiceNow downloader writes.
slurm context Slurm partitions, nodes, reservations and job summaries from an exported snapshot, with live squeue and sinfo tools and gated drain, resume and requeue actions.
ticket-triage automation Triages new and updated Redmine, JIRA and ServiceNow tickets - a cited triage draft for a person to send (L1), or a status or assignment change or a posted reply that runs only after a person approves it (L2).
tickets context Generic tracker tickets from Redmine, any JIRA, or both, read from the records cache the tickets downloader writes.
twiki context TWiki topics, read from an EOS dump of the wiki's raw markup.
