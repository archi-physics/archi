Pack: indico

Indico events and their talks, read live from the Indico HTTP API.

Field Value
Kind context
Version 0.2.0
Needs a credential to publish no
Okg modules it needs document_starter, person, extraction
Packs it needs none

In which bundles

  • Default in: cern-team
  • Optional in: none

Add it to an instance with archi add indico.

Sources

  • indico.indico_live

Questions

archi init asks these. Answer one with --answer indico_<id>=VALUE.

Id Type Required Default Prompt
base_url string no https://indico.cern.ch Indico server URL
event_ids string no [] Indico event ids to read, as a YAML list (for example '["1716863"]')
category_ids string no [] Indico category ids to read, as a YAML list (for example '["100"]')

Credentials

The manifest names no credential variable.

Freshness limits

archi doctor compares each source's age with its limit.

Source Longest acceptable age
indico.indico_live 24h

Invariants

The pack owns these checks. They leave with it.

Name Severity What it checks
indico_coverage error The Indico source must have live meetings. Required live subtypes: meeting_minutes. A missing one means the input was empty or the connector regressed.
