Pack: cms-catalogs

CMS computing catalogs - CRIC, CRIC core, SITECONF, DBS, WMStats, GOCDB and CondDB.

Field Value
Kind context
Version 0.1.0
Needs a credential to publish yes
Okg modules it needs document_starter, person, extraction, dataset
Packs it needs none

In which bundles

  • Default in: cms-comp-ops
  • Optional in: none

Add it to an instance with archi add cms-catalogs.

Sources

  • cms-catalogs.conddb_global_tags
  • cms-catalogs.cric
  • cms-catalogs.cric_core
  • cms-catalogs.dbs_datasets
  • cms-catalogs.gocdb_downtimes
  • cms-catalogs.siteconf
  • cms-catalogs.wmstats_workflows

Questions

archi init asks these. Answer one with --answer cms_catalogs_<id>=VALUE.

Id Type Required Default Prompt
gitlab_url string no https://gitlab.cern.ch GitLab server holding the SITECONF group

Credentials

The pack reads these environment variables. Only the names are listed. Put each value in the instance's .env (KEY=value, one per line): archi add and archi ingest pass it to ingestion. A value exported in the shell wins. okg run by hand does not read .env.

  • CERN_GITLAB_TOKEN

Freshness limits

archi doctor compares each source's age with its limit.

Source Longest acceptable age
cms-catalogs.conddb_global_tags 7d
cms-catalogs.cric 7d
cms-catalogs.cric_core 7d
cms-catalogs.dbs_datasets 7d
cms-catalogs.gocdb_downtimes 24h
cms-catalogs.siteconf 7d
cms-catalogs.wmstats_workflows 24h

Link coverage targets

Name From Edge To Direction Minimum share Severity
storage_endpoint_site storage_endpoint contains site in 0.9 warn
compute_endpoint_site compute_endpoint contains site in 0.9 warn
site_config_site site_config contains site in 0.8 warn
workflow_input_dataset workflow consumes dataset out 0.5 warn

Invariants

The pack owns these checks. They leave with it.

Name Severity What it checks
cms_catalogs_coverage error The CMS catalog sources must each have live records. Required live subtypes: site, infrastructure_service, site_config, dataset, workflow, downtime, global_tag. A missing one means the input was empty or the connector regressed.
