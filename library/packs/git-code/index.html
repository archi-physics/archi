Pack: git-code

One Git repository's tracked files and history (commits, tags, authors, per-file diffs).

Field Value
Kind context
Version 0.1.0
Needs a credential to publish no
Okg modules it needs document_starter, person, extraction, git_graph
Packs it needs none

In which bundles

  • Default in: none
  • Optional in: cern-team, cluster-manager, cms-comp-ops

Add it to an instance with archi add git-code.

Sources

  • git-code.git_history
  • git-code.repo

Questions

archi init asks these. Answer one with --answer git_code_<id>=VALUE.

Id Type Required Default Prompt
repo_name string no repo short name for the repository (graph identity)
repo_url string yes Git URL of the repository to ingest

Credentials

The manifest names no credential variable.

Freshness limits

archi doctor compares each source's age with its limit.

Source Longest acceptable age
git-code.git_history 7d
git-code.repo 7d

Link coverage targets

Name From Edge To Direction Minimum share Severity
tag_commit git_tag references git_commit out 0.95 warn

Invariants

The pack owns these checks. They leave with it.

Name Severity What it checks
git_code_coverage error The repository sources must have live files and commits. Required live subtypes: source_file, git_commit. A missing one means the input was empty or the connector regressed.

Playbooks

The pack ships no playbook.
