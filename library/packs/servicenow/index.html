Pack: servicenow

ServiceNow incidents, requests and knowledge-base articles, read from the records cache the ServiceNow downloader writes.

Field Value
Kind context
Version 0.1.0
Needs a credential to publish yes
Okg modules it needs document_starter, person, extraction
Packs it needs none

In which bundles

  • Default in: none
  • Optional in: cluster-manager

Add it to an instance with archi add servicenow.

Sources

  • servicenow.servicenow

Questions

archi init asks these. Answer one with --answer servicenow_<id>=VALUE.

Id Type Required Default Prompt
instance_url string yes ServiceNow instance URL
auth_method string no oauth ServiceNow authentication, oauth or basic

Credentials

The pack reads these environment variables. Only the names are listed. Put each value in the instance's .env (KEY=value, one per line): archi add and archi ingest pass it to ingestion. A value exported in the shell wins. okg run by hand does not read .env.

  • SERVICENOW_CLIENT_ID
  • SERVICENOW_CLIENT_SECRET
  • SERVICENOW_USERNAME
  • SERVICENOW_PASSWORD

Freshness limits

archi doctor compares each source's age with its limit.

Source Longest acceptable age
servicenow.servicenow 24h

Link coverage targets

Name From Edge To Direction Minimum share Severity
incident_reporter servicenow_incident reported_by person out 0.8 warn

Invariants

The pack owns these checks. They leave with it.

Name Severity What it checks
servicenow_coverage error The ServiceNow source must have live incidents. Required live subtypes: servicenow_incident. A missing one means the input was empty or the connector regressed.

Playbooks

The pack ships no playbook.
