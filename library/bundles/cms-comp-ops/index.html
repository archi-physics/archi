Bundle: cms-comp-ops

A CMS computing operations knowledge instance - sites, storage, datasets and workflows from the CMS catalogs, site status, CMSSW releases, and the operational memory of past incidents.

Field Value
Version 0.3.0
Extends cern-team
Okg versions it supports >=0.6.0,<0.7

Packs

  • Default: cms-catalogs, cmssst, cmssw-releases, ops-record
  • Optional: monit-live, dqm, hypernews, jira, git-code, ticket-triage
  • With git-code, also: code-text (opt out with --without)

Default packs install with the bundle. Add an optional pack with --with <pack> at init, or archi add <pack> later. The bundle also installs the default packs of the bundles it extends.

archi init myteam --bundle cms-comp-ops

Chat preset

Setting Value
site_name CMS computing operations chat

Suggested questions:

  • Which storage endpoints does a given site have, and what is its status?
  • Which workflows read a given dataset, and where is it hosted?
  • Which downtimes are scheduled for a site, and what happened the last time it had one?

Automation level bounds

The bundle sets no bound. Each automation pack's own limit applies.
