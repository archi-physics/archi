# Design records

The decisions behind Archi 3.0 are in two architecture decision records
(ADRs). They live in the repository, outside this site.

- [ADR 0002: Archi 3.0, automating operations on a solid context layer](https://github.com/archi-physics/archi/blob/archi_v3/docs/adr/0002-archi-3.0-release.md).
  What Archi is, the decisions D1 to D13, packs and bundles, the context
  layer, the operations layer and the setup path. Start here.
- [ADR 0001: Archi v3 program spec](https://github.com/archi-physics/archi/blob/archi_v3/docs/adr/0001-archi-v3-program-spec.md).
  The program the 3.0 release builds on. ADR 0002 amends it.

Other design notes kept in the repository's `docs/` folder:

- [OKG alignment page](https://github.com/archi-physics/archi/blob/archi_v3/docs/okg-alignment.md):
  the OKG surface Archi uses.
- [Upstream asks for the golden path](https://github.com/archi-physics/archi/blob/archi_v3/docs/golden-path-akmon-asks.md)
  and [for the ops runtime](https://github.com/archi-physics/archi/blob/archi_v3/docs/ops-runtime-akmon-asks.md):
  the changes Archi needs from OKG.
- [Cache snapshots](https://github.com/archi-physics/archi/blob/archi_v3/docs/cache-snapshot.md):
  shipping connector caches without CERN access.
- [The long cern-team quickstart](https://github.com/archi-physics/archi/blob/archi_v3/docs/cern-team-quickstart.md),
  kept as reference.
