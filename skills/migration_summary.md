# CMS Migration Summary

Use this skill for questions about CMS migrations, commissioning, protocol
changes, endpoint moves, tape transitions, cleanup, or operational rollouts.

## Expansion Pattern

- Start with the entity names in the question: site, RSE, endpoint hostname,
  protocol, service, campaign, or ticket key.
- Search related terms: migration, commissioning, testing, cleanup, rollback,
  re-enable, disable, WebDAV, SRM, CTA, Tape REST, FTS, Rucio, subscription,
  and rule cleanup.
- Expand from the first ticket into linked issue families, cleanup tickets,
  temporary test artifacts, endpoint aliases, and current catalog/RSE status.
- Separate timeline, current status, and unresolved gaps.

## Answer Shape

- One-sentence summary.
- Timeline bullets with dates only when directly evidenced.
- Operational impact and current status.
- Evidence IDs grouped by ticket, documentation, and graph entity.
- Gaps when no authoritative completion date or current operational state was
  found in the queried generation.
